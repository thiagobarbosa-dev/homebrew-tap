# thiagobarbosa-dev Homebrew Tap

[![Homebrew](https://img.shields.io/badge/homebrew-tap-blue.svg)](https://brew.sh)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Welcome to my personal Homebrew tap. Here you can find custom formulas for various CLI tools and utilities I develop.

## 🚀 How to Install

To add this tap to your Homebrew installation, run:

```bash
brew tap thiagobarbosa-dev/tap
```

## 📦 Available Formulas

| Formula | Description | Install Command |
| :--- | :--- | :--- |
| **whatscli** | WhatsApp Web CLI powered by Baileys | `brew install whatscli` |

---

### whatscli

WhatsApp Web CLI that allows you to interact with WhatsApp directly from your terminal.

**Usage:**
```bash
whatscli --help
```

For more details, visit the [whatscli repository](https://github.com/thiagobarbosa-dev/whatscli).

## 🔄 Updating Formulas

To update the formulas in this tap, run:

```bash
brew update
brew upgrade <formula-name>
```

Or to upgrade everything:

```bash
brew upgrade
```

## 🛠 Troubleshooting

If you encounter any issues with the formulas, please ensure your Homebrew is up to date:

```bash
brew update
brew doctor
```

For specific issues related to the tools, please open an issue in the respective tool's repository.
